# Hospital Data Analysis

## 📌 About the Project

This is a Data Science project based on Hospital Patient Data Analysis.
The project uses Python libraries such as Pandas, Seaborn, and Matplotlib
to analyze patient information and create meaningful data visualizations.

## 🎯 Objective

The main objective of this project is to analyze hospital patient data,
identify patterns and relationships in the data, and represent the findings
using different statistical methods and visualizations.

## 🛠️ Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Google Colab
- Microsoft Excel

## 📂 Dataset

The hospital dataset contains information about patients, including:

- Patient ID
- Age
- Gender
- Department
- Treatment Cost
- Stay Days
- Heart Rate
- Treatment Result

## 🔎 Data Analysis

The following analysis was performed:

- Dataset inspection
- First and last records
- Dataset shape
- Data types
- Statistical summary
- Mean, maximum, and minimum values
- Department-wise patient count
- Gender-wise patient count
- Treatment result analysis
- Age group analysis
- Correlation analysis
- Maximum and minimum value identification

## 📊 Data Visualization

Different types of charts were created to understand the data:

- Bar Chart
- Pie Chart
- Histogram
- Box Plot
- Scatter Plot
- Correlation Heatmap
- Line Plot

## 📈 Key Visualizations

### Patients by Department
Shows the number of patients in each hospital department.

### Gender Distribution
Shows the distribution of patients based on gender.

### Treatment Cost by Department
Compares treatment costs across different departments.

### Age vs Treatment Cost
Shows the relationship between patient age and treatment cost.

### Stay Days vs Treatment Cost
Shows the relationship between hospital stay duration and treatment cost.

### Age vs Heart Rate
Shows the relationship between patient age and heart rate.

### Correlation Heatmap
Shows the correlation between Age, Treatment Cost, Stay Days, and Heart Rate.

## ▶️ How to Run the Project

1. Open `hospital.ipynb` in Google Colab.
2. Upload or keep `hospital.xlsx` in the working environment.
3. Run the Python code cells.
4. View the analysis results and visualizations.
